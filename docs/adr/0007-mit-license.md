# 7. MIT license

Date: 2026-11-03

## Status

Accepted

## Context

Stashbook is developed in a public GitHub repository. Without a license, nobody else has permission to use, copy, or modify the code, even though they can read it.

## Decision

License Stashbook under the MIT License. The license text is in `LICENSE` at the project root.

## Consequences

- Anyone can use, copy, modify, and distribute the code, including in commercial projects, as long as they keep the copyright and license notice.
- The software is provided as-is, with no warranty.
- GitHub shows the license on the repository page.
